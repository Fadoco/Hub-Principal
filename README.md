## O que você encontra

- **Clima e previsão:** condições atuais, próximas horas e previsão dos próximos dias, com chance e horário estimado do pico de chuva quando disponível.
- **Satélite:** imagens meteorológicas recentes do INMET, com controles para animar e escolher os horários.
- **Notícias:** manchetes organizadas por assuntos, com links para abrir as fontes.
- **Cotações e atalhos:** valores de referência do dólar e do euro, além de links úteis.
- **Modo TV:** visualização ampliada de clima e satélite para telas maiores.

## Como usar

1. Abra o [site](https://fadoco.github.io/Hub-Principal/) ou instale o app pelo botão de download acima.
2. Permita o acesso à localização para ver o clima da sua região. Se preferir, use **Ver clima em outro local** e pesquise uma cidade.
3. No app, use a navegação inferior: **Início**, **Satélite**, **Notícias** e **Mais**.
4. Toque em **Atualizar clima** para consultar as condições novamente. Os horários são exibidos no fuso local do dispositivo.
5. Se ficar sem internet, alguns dados consultados anteriormente podem continuar disponíveis no aparelho.

No computador, o site funciona no navegador. No Android, o app pode avisar quando houver uma atualização disponível; você decide se deseja baixá-la e confirma a instalação.

## Créditos e fontes

O Hub reúne dados e serviços de terceiros. Consulte as fontes originais:

- [Open-Meteo](https://open-meteo.com/) — dados meteorológicos e previsões.
- [INMET](https://www.gov.br/inmet/pt-br) — imagens meteorológicas GOES; [visualizador de satélite](https://satelite.inmet.gov.br/).
- [OpenStreetMap](https://www.openstreetmap.org/copyright) e [Nominatim](https://nominatim.org/) — mapas e busca de cidades.
- [AwesomeAPI](https://docs.awesomeapi.com.br/) — cotações de moedas.
- [Bing Notícias](https://www.bing.com/news) — manchetes; [Google Notícias](https://news.google.com/) — buscas externas.
- [IPMet/UNESP](https://www.ipmetradar.com.br/) — links para mapas e radares oficiais.
- [Cloudflare Workers](https://workers.cloudflare.com/) — infraestrutura usada para disponibilizar o feed de notícias.
- [Fadoco](https://github.com/Fadoco) — desenvolvimento e manutenção do projeto.

Os dados podem sofrer atrasos, mudanças ou indisponibilidade conforme cada serviço. A previsão é informativa e não substitui alertas oficiais.
